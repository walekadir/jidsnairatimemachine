Jid's Naira Time Machine 

A lightweight, interactive inflation visualizer that calculates exactly how much purchasing power the Nigerian Naira has lost over the last decade. 

Instead of just looking at inflation percentages, this tool translates historical data into tangible metrics: US Dollars, Liters of Fuel, and Bags of Rice.

Features
Time Travel Calculation: Enter an amount and pick a past year (2010–2025) to see its equivalent value today.

Tangible Metrics: Compares purchasing power using real-world items (USD, PMS/Fuel, 50kg Rice).

Custom Data Visualization: Features a dynamic, auto-scaling bar chart built entirely from scratch using the HTML5 Canvas API.

Fully Responsive: Sleek dark-mode UI that works perfectly on desktop and mobile.

Tech Stack
 HTML5
 CSS3 (Custom variables, responsive grid)
 Vanilla JavaScript (DOM manipulation, Canvas API for charting)
 Zero external dependencies (Single-file architecture)

How to Run
Since this is a vanilla HTML/JS app contained entirely in one file, you don't need a build step or package manager. 
1. Clone the repository.
2. Open `time-machine.html` in any modern web browser.
